# Experiments

存放各个实验的结果。

## 命名规则

`exp-XXX-简短描述/`

例如：
- `exp-001-todo-app/`
- `exp-002-retro-game-maker/`
- `exp-003-daw-music-workstation/`

## 每个实验目录结构

```
exp-XXX-name/
├── product-spec.md          # Planner 产出
├── sprint-1/
│   ├── sprint-1-contract.md    # Sprint 合同
│   ├── sprint-1-code/          # Generator 代码
│   └── sprint-1-eval.md        # Evaluator 报告
├── sprint-2/
│   └── ...
├── final-app/               # 最终合并的应用
├── experiment-log.md        # 实验日志
└── README.md                # 实验总结
```
